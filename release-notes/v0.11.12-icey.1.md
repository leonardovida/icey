## Highlights

- This is the first release of Icey, a performance-focused fork of [Ice](https://github.com/jordanbaird/Ice), the open-source menu bar manager for macOS.
- Icey uses much less CPU and energy. It no longer listens to every mouse move, drag and scroll in the system, and no longer polls the Accessibility API every millisecond after each app switch ([#1](https://github.com/leonardovida/icey/pull/1)).
- Icey puts less load on the WindowServer. It takes fewer screen captures, fixes memory leaks, and stops busy-waiting while moving items ([#1](https://github.com/leonardovida/icey/pull/1)).

## Upgrading from Ice

Icey is based on Ice 0.11.12. It uses the same bundle identifier and settings as Ice, so it replaces an existing Ice install.

1. Quit Ice.
2. Download `Icey-0.11.12-icey.1.dmg` below and drag `Ice.app` to Applications, replacing the existing app.
3. Grant Accessibility and Screen Recording again when asked. Icey is signed with a different developer certificate than Ice, so macOS treats it as a new app.
4. Turn off "Automatically check for updates" in Settings > About. This stops Ice's updater from replacing Icey with a future upstream release.

Check the [Compatibility](#compatibility) section before upgrading, especially on macOS 26 Tahoe.

## Bug Fixes

All changes are from [#1](https://github.com/leonardovida/icey/pull/1).

- **Mouse movement:** moving the mouse raised Ice's energy use even with "Show on hover" off. Event monitors now only run when the settings that use them are on (upstream [#334](https://github.com/jordanbaird/Ice/issues/334), [#479](https://github.com/jordanbaird/Ice/issues/479)).
- **App switching:** with menu bar appearance settings on, CPU use spiked after every app switch. Polling now backs off, and only runs for the split shape (upstream [#578](https://github.com/jordanbaird/Ice/issues/578)).
- **Ice Bar:** after the Ice Bar was shown once, Ice captured the menu bar every 5 seconds forever. It now only does this while the Ice Bar is visible (upstream [#819](https://github.com/jordanbaird/Ice/issues/819)).
- **Desktop wallpaper:** Ice captured the wallpaper even when the configuration never draws it. It now only does this for the full and split shapes.
- **Memory:** memory grew over long runtimes. A capture leak is fixed, and the item image cache no longer grows without bound (upstream [#530](https://github.com/jordanbaird/Ice/issues/530)).
- **Unresponsive apps:** a hung frontmost app could freeze Ice for about 6 seconds at a time. Accessibility calls now time out after 1 second.
- **Moving items:** moving an item could hang forever when a modifier key was released at the wrong moment. Item caching then stopped for good. Waiting for released modifier keys now polls instead.
- **Appearance settings:** turning them off left the overlay panels running until relaunch. They are now removed.

## Compatibility

- **macOS 26 Tahoe:** this release does not include upstream's 0.11.13-dev changes for menu bar item ownership. On Tahoe, the layout settings, the Ice Bar and search may show "Unable to display menu bar items". If you rely on those features on Tahoe, stay on Ice 0.11.13-dev.2 until a later Icey release ports the fix.
- **Show on hover:** Ice now checks for an empty menu bar space at most about 20 times per second while the pointer moves over app menus or items, instead of on every mouse event.
- **Accessibility reads:** reads that take longer than 1 second now fail and are retried on the next update.

## Maintenance

- The app and DMG are signed with a Developer ID certificate and notarized by Apple, so they open without Gatekeeper warnings. Builds are universal (Apple silicon and Intel). SHA-256 checksums are in `SHA256SUMS.txt`.

## Highlights

- **macOS 26 Tahoe works.** Icey now builds on upstream Ice 0.11.13-dev.2, the Tahoe rewrite. The Menu Bar Layout pane, the Ice Bar and search show your items again, and the redesigned Liquid Glass settings come with it ([#5](https://github.com/leonardovida/icey/pull/5)).
- **Early macOS 27 support.** Hiding items, the Ice Bar and the layout editor work again on macOS 27. This comes from community work for upstream Ice that upstream never merged (jordanbaird/Ice#995 and the follow-ups in jordanbaird/Ice#1001), plus fixes measured on macOS 27 ([#5](https://github.com/leonardovida/icey/pull/5)).
- **Low resource use, and about 40 upstream bugs fixed.** The performance work from 0.11.12-icey.1 is carried over to the new code. This release also fixes crashes, a stuck update prompt, multi-display problems and a hang when a menu bar item stops responding ([#5](https://github.com/leonardovida/icey/pull/5)).

## Upgrading from 0.11.12-icey.1 or Ice

The version number follows the upstream code Icey is built on: Ice 0.11.13-dev.2, upstream's last prerelease. In Icey, that code is a regular, supported release. Its build number (1121) is higher than any Ice release, so this version replaces Ice 0.11.12 and Ice 0.11.13-dev.2.

1. Quit Ice or Icey.
2. Download `Icey-0.11.13-dev.2-icey.1.dmg` below, open it, and drag `Icey.app` to Applications. Then move the old `Ice.app` to the Trash: both share a bundle identifier.
3. Open Icey.
   - From Icey 0.11.12-icey.1, Accessibility and Screen Recording carry over, because both releases have the same Developer ID signature.
   - From Ice or from a build you made yourself, grant both permissions again.
4. Check your menu bar appearance settings. They reset once during this upgrade (see [Compatibility](#compatibility)).
5. Optionally, turn on "Automatically check for updates" in Settings > About. From this release, Icey updates itself from Icey's GitHub releases.

Changes to check before you upgrade, all in [Compatibility](#compatibility):

- The app is renamed to `Icey.app`. Remove the old `Ice.app`.
- Menu bar appearance settings reset once.
- "Show section dividers" is now "Section divider style".
- On macOS 27, some settings are hidden because they have no effect.

## Features

- **macOS 27 support** ([#5](https://github.com/leonardovida/icey/pull/5)):
  - Hiding and showing items, the Ice Bar and the Menu Bar Layout editor work again (from jordanbaird/Ice#995).
  - The search panel can open hidden items (jordanbaird/Ice#1001).
  - Items are sorted into the right section when an app that only has a menu bar item launches or quits (jordanbaird/Ice#1001).
  - The menu bar appearance finds the wallpaper, and the split shape draws both halves (jordanbaird/Ice#1001).
  - Settings that do nothing on macOS 27 are hidden, and layout items macOS 27 can't move are disabled with a tooltip that says why (jordanbaird/Ice#1001).
- **From upstream Ice 0.11.13-dev.2** ([#5](https://github.com/leonardovida/icey/pull/5)):
  - A Liquid Glass design and reorganized settings.
  - A choice of section divider style.
  - An option to turn off the context menu that appears when you right-click the menu bar.
- **Updates from Icey:** the built-in updater now gets new versions from Icey's GitHub releases. Before, it used Ice's update feed, so it could only ever offer Ice ([#5](https://github.com/leonardovida/icey/pull/5)).
- **Permissions** ([#5](https://github.com/leonardovida/icey/pull/5)):
  - Screen Recording granted while Icey runs in limited mode now takes effect without a relaunch (adapted from jordanbaird/Ice#928).
  - Each missing permission now explains what to do when System Settings shows it as enabled but Icey still asks for it (jordanbaird/Ice#1004).

## Bug Fixes

All fixes are in [#5](https://github.com/leonardovida/icey/pull/5). Upstream pull requests that fixes were taken from are credited in each commit.

- **macOS 26 Tahoe layout:** the Menu Bar Layout pane, the Ice Bar and search showed "Unable to display menu bar items" or empty sections. They now show your items. The helper Icey uses to identify items now also connects in builds without an Apple developer team (jordanbaird/Ice#973, #951, #999, with fixes from #953 and #950).
- **macOS 27 system items:**
  - Screen Mirroring disappeared from the menu bar. It now stays (jordanbaird/Ice#954).
  - With an app's item among the system items, clicking the battery opened that app, and Wi-Fi didn't open. Each click now reaches the item you clicked (jordanbaird/Ice#1014).
- **Crashes on macOS 26:** Ice 0.11.12 and Icey 0.11.12-icey.1 could crash when you clicked the menu bar or the Ice icon, or turned on the Ice Bar with the Dynamic location. The code that crashed is gone, and similar conversions elsewhere no longer crash on unexpected values (jordanbaird/Ice#947, #977, #925, with a fix from #956).
- **Update prompt:** the "Check for updates automatically?" dialog could open behind other windows, ignore input, and come back on every launch. It now comes to the front and stays answered (jordanbaird/Ice#969, #937, #931).
- **Multiple displays and fullscreen:**
  - A space or display change while the Ice Bar was opening, such as a video entering fullscreen on another display, left an empty bar on screen. The bar now stays closed (jordanbaird/Ice#986).
  - The menu bar appearance used the fullscreen state of whichever display had focus, so the split shape broke in fullscreen. Each display now uses its own (jordanbaird/Ice#959, #988).
- **Unresponsive apps:** a hung app could leave Icey stuck and the menu bar hidden. Accessibility calls now give up after 1 second (jordanbaird/Ice#968).
- **Stuck item moves and clicks:** if a menu bar item never responded, moving or clicking it could wait forever. Icey's mouse and keyboard handling stayed blocked until a relaunch. The wait now times out and retries.
- **Timed auto-rehide** stopped working after the first time the pointer stayed in the menu bar when the timer fired. It now re-arms.
- **Menu Bar Layout pane:** it could turn solid white when the menu bar color couldn't be read. It now stays readable (from jordanbaird/Ice#972).
- **Item spacing:** applying spacing stopped relaunching apps after the first system app. It now relaunches every app (from jordanbaird/Ice#1012).
- **Item images:** when macOS didn't say which display had the active menu bar, item images were never cached. Icey now uses the main display (from jordanbaird/Ice#922).
- **Limited mode:** the "Continue in Limited Mode" text is now readable (from jordanbaird/Ice#942).
- **Ice Bar closing early:** with timed or hover auto-rehide, the Ice Bar could close while you moved the pointer down to it. The area of the Ice Bar now counts as inside, including during the moment before it appears (jordanbaird/Ice#914).
- **Split shape brightness:** with the split shape, the area around the shape looked brighter than the rest of the menu bar, because Icey captured the wallpaper without the system's dimming layer. That layer is now included (jordanbaird/Ice#943).
- **Empty layout pane:** when Icey's divider was missing from the menu bar, for example after turning Icey off in System Settings > Menu Bar, the Menu Bar Layout pane kept loading forever. It now says what's wrong and how to fix it (jordanbaird/Ice#919).
- **Tint on the wrong display:** an appearance overlay that ended up on another display, such as an iPad used as an extended display, showed a tint strip there. It now hides itself (jordanbaird/Ice#910).
- **Endless retries:** an item that couldn't be moved back to its section was retried every 3 seconds forever. Retries now back off and stop after five rounds. Icey also recovers on its own when its divider reappears (jordanbaird/Ice#908).
- **Performance on the new code:**
  - Mouse, scroll and drag monitors only run when a setting uses them (jordanbaird/Ice#334, #479).
  - Show on hover checks at most every 50ms over menus and items.
  - After an app switch, Icey no longer polls the app menu every millisecond (jordanbaird/Ice#578).
  - Menu bar captures for the Ice Bar only run while it is visible (jordanbaird/Ice#819).
  - The wallpaper is only captured for shapes that draw it.
  - Unused appearance overlays are removed.
  - The item image cache is pruned (jordanbaird/Ice#530).
  - Item windows are read in one window server call.
  - Timers allow the system to coalesce wakeups.

## Compatibility

- **The app is now `Icey.app`.** Menus, settings and About say Icey. The bundle identifier is unchanged, so settings carry over. Remove the old `Ice.app`, and turn "Launch at login" off and on again if you used it.
- **Menu bar appearance settings reset once.** The upstream 0.11.13 settings migration clears the saved appearance (tint, shadow, border and shape). Set it again in Settings > Menu Bar Appearance after upgrading. If you go back to Ice 0.11.12 or Icey 0.11.12-icey.1 afterwards, your old appearance settings are not restored there either.
- **Section dividers:** "Show section dividers" is replaced by "Section divider style". Your choice is migrated automatically: dividers on becomes the chevron style, off becomes no divider.
- **macOS 27:**
  - The section divider style, "Hide application menus" and the temporary show interval have no effect on macOS 27, so Icey hides them there. macOS 27 folds items that don't fit behind its own overflow button.
  - In the layout editor, items without a bundle identifier, and items macOS always shows, can't be moved to another section. They are disabled with a tooltip.
  - This support is new, and was tested by the contributors who wrote it rather than on the maintainer's Mac. Please [report problems](https://github.com/leonardovida/icey/issues/new/choose).
- **Permissions:** if System Settings shows Accessibility or Screen Recording as enabled but Icey still asks for it, remove Ice from that list with the minus button, then add it again.
- **Old `Ice.app` copies:** keep only one copy. On macOS 27, a second copy with the same bundle identifier can make macOS hide Icey's own icon.
- **Updates:** the built-in updater now checks [Icey's GitHub releases](https://github.com/leonardovida/icey/releases) instead of Ice's update feed, and only accepts updates signed with Icey's key. Ice can no longer replace Icey through an update. Versions before this one still check Ice's feed, so install this release by hand once.
- **Split shape:** after an app switch, the split shape may take up to a second to follow a change in the app menu's width.

All changes that need action are also listed in [BREAKING_CHANGES.md](https://github.com/leonardovida/icey/blob/main/BREAKING_CHANGES.md).

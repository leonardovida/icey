## Highlights

- **A Liquid Glass look on macOS 26.** A new layered app icon, a glass search panel and icons in Icey's menu ([#12](https://github.com/leonardovida/icey/pull/12)).
- **12 more Ice bugs fixed:** apps with several menu bar items (such as OneDrive), second displays, menu bars that hide automatically, mouse-wheel scrolling and "Hide application menus". See the [full list](https://leonardovida.github.io/icey/fixes/) ([#11](https://github.com/leonardovida/icey/pull/11), [#14](https://github.com/leonardovida/icey/pull/14)).

## Features

- **App icon:** a layered icon that macOS 26 renders with Liquid Glass in the default, dark, clear and tinted styles. Before, macOS 26 showed the old icon on a gray backing ([#12](https://github.com/leonardovida/icey/pull/12)).
- **Search panel:** a glass panel on macOS 26, like Spotlight. On every version, the field has a search icon, and a search with no matches says so ([#12](https://github.com/leonardovida/icey/pull/12)).
- **Menu:** on macOS 26, each item in Icey's menu has an icon ([#12](https://github.com/leonardovida/icey/pull/12)).
- **Permissions window:** clearer text, a checkmark for granted permissions, and Return to continue ([#12](https://github.com/leonardovida/icey/pull/12)).

## Bug Fixes

Each fix says what went wrong before, and what happens now.

- **Apps with several menu bar items, such as OneDrive with more than one account:**
  - Before: clicking one of the app's hidden items made Icey treat all of them as shown. The others disappeared from Icey's item list, and when the items were hidden again, Icey could move the wrong one.
  - Now: Icey tracks each item on its own, so only the item you clicked is shown and put back ([jordanbaird/Ice#857](https://github.com/jordanbaird/Ice/issues/857), [#739](https://github.com/jordanbaird/Ice/issues/739), [#404](https://github.com/jordanbaird/Ice/issues/404)).
- **A second display when "Displays have separate Spaces" is off:**
  - Before: Icey treated the top of every display as a menu bar, but with that setting off only the main display has one. Clicks near the top of the other displays, such as on a browser tab or a window title, were swallowed, and right-clicks opened Icey's menu.
  - Now: Icey only reacts at the top of a display that has a menu bar ([jordanbaird/Ice#456](https://github.com/jordanbaird/Ice/issues/456), [#646](https://github.com/jordanbaird/Ice/issues/646), [#639](https://github.com/jordanbaird/Ice/issues/639), [#383](https://github.com/jordanbaird/Ice/issues/383)).
- **"Automatically hide and show the menu bar" turned on in System Settings:**
  - Before: Icey only counted the top pixel row of the screen as the menu bar. Show on hover, click and scroll needed the pointer pressed against the screen edge, and shown items or the Ice Bar closed as soon as the pointer moved down onto the menu bar.
  - Now: the whole menu bar counts, once it slides into view ([jordanbaird/Ice#708](https://github.com/jordanbaird/Ice/issues/708), [#286](https://github.com/jordanbaird/Ice/issues/286), [#331](https://github.com/jordanbaird/Ice/issues/331)).
- **Show on scroll with a mouse wheel:**
  - Before: it only worked on a trackpad. A wheel scrolls in small steps that never reached Icey's trigger.
  - Now: one notch of the wheel shows or hides the items ([jordanbaird/Ice#717](https://github.com/jordanbaird/Ice/issues/717)).
- **"Hide application menus" with the always-hidden section turned off:**
  - Before: the app's menus (File, Edit and so on) stayed visible under the items you revealed, because Icey skipped exactly those items when it checked for overlap.
  - Now: the menus hide when revealed items need the space ([jordanbaird/Ice#434](https://github.com/jordanbaird/Ice/issues/434)).
- **An item clicked from the Ice Bar or search, partly fixed:**
  - Before: if the item next to it was recreated while it was shown, for example when that app restarted, Icey couldn't put it back. It stayed in the visible menu bar.
  - Now: Icey finds the neighbor again, or returns the item to the end of the section it came from ([jordanbaird/Ice#729](https://github.com/jordanbaird/Ice/issues/729)).

These fixes come from reading the code and the reports. None was reproduced on a multi-display or auto-hiding menu bar setup, so please [report](https://github.com/leonardovida/icey/issues/new/choose) anything that still happens.

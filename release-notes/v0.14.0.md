## Highlights

- **Anonymous statistics, so Icey can be tuned for the Macs it runs on.** Once a day, Icey sends its version, the macOS version, Mac model, CPU, memory, number of displays and which features are on. Nothing identifies you or your Mac, and you can turn it off in Settings > About ([#45](https://github.com/leonardovida/icey/pull/45)).
- **Less memory and smoother panels.** Item images no longer span two menu bars on stacked displays, and the Ice Bar, search and Menu Bar Layout pane stop redrawing when nothing changed ([#46](https://github.com/leonardovida/icey/pull/46), [#47](https://github.com/leonardovida/icey/pull/47)).
- **Faster Ice Bar, search and launch.** Colour captures run off the main thread, search rows are cheaper, and Icey does less work at launch ([#48](https://github.com/leonardovida/icey/pull/48), [#49](https://github.com/leonardovida/icey/pull/49), [#50](https://github.com/leonardovida/icey/pull/50), [#51](https://github.com/leonardovida/icey/pull/51)).

## Upgrading from 0.13.0

Nothing to do. Your settings, item layout, hotkeys and permissions stay as they are.

1. Wait for Icey to offer the update, or choose Settings > About > **Check for Updates**.
2. Install it, and Icey restarts on its own.
3. If you don't want to send anonymous statistics, turn off Settings > About > **Send anonymous statistics**.

## Features

- **Anonymous statistics:** Settings > About > **Send anonymous statistics**, on by default ([#45](https://github.com/leonardovida/icey/pull/45)).
  - Sent at most once a day: Icey version and build, macOS version, Mac model (such as Mac15,10), CPU type, cores and memory, number of displays, whether one has a notch, Icey's language, and which Icey features and options are on.
  - Never sent: names, item names, app lists, hotkeys, display names or any identifier. The server doesn't store IP addresses, and it keeps only the day and hour a report arrived.
  - The reports go to Icey's own service, whose code is public at [leonardovida/icey-stats](https://github.com/leonardovida/icey-stats). See [Privacy and anonymous statistics](https://github.com/leonardovida/icey#privacy-and-anonymous-statistics) in the README.
- **Website visit counter:** the Icey website counts page views and DMG downloads without cookies, and sends nothing when your browser asks sites not to track you ([#45](https://github.com/leonardovida/icey/pull/45)).

## Bug Fixes

### Speed, energy and memory

- **Memory spikes with stacked displays:**
  - Before: with a display above another, one item image capture covered both menu bars. In a test that made a 68 MB image, which stayed in memory until the next capture.
  - Now: each menu bar is captured on its own, and search and the Menu Bar Layout pane take one capture per menu bar for all sections ([#46](https://github.com/leonardovida/icey/pull/46)).
- **Redraws with nothing new:**
  - Before: while the Ice Bar, search or the Menu Bar Layout pane was open, Icey captured the items every 3 seconds and redrew everything, even when the images were the same.
  - Now: identical images are kept, so nothing redraws. If the Ice Bar stays open while you change the menu bar appearance or switch between light and dark, it now updates at once ([#47](https://github.com/leonardovida/icey/pull/47)).
- **Colour captures:** the Ice Bar, search and Settings read the menu bar's colour off the main thread. The Ice Bar opens about 6 ms sooner and still appears with the right colour ([#48](https://github.com/leonardovida/icey/pull/48)).
- **Search:** each item's name and icon are worked out once, and rows redraw only when they change, so a keystroke costs about half as much ([#49](https://github.com/leonardovida/icey/pull/49)).
- **Finding each item's app (macOS 26 and later):** Icey's helper looks up all items in one request and asks each app once. At launch on a test Mac this took 94 checks instead of 456 ([#50](https://github.com/leonardovida/icey/pull/50)).
- **Launch:** the Settings window's content is built when you first open it, not at launch ([#51](https://github.com/leonardovida/icey/pull/51)).

### Other fixes

- **Search panel reopening:** if you closed the search panel while it was still opening, it could appear anyway. Now it stays closed ([#48](https://github.com/leonardovida/icey/pull/48)).

## Compatibility

- **Anonymous statistics are on by default:** if you'd rather not send them, turn off Settings > About > **Send anonymous statistics**. Nothing is sent while it is off.
- **First Settings open after launch:** it takes a few hundredths of a second longer, because the window's content is no longer built at launch.

## Maintenance

- Release download counts, stars and GitHub traffic are collected once a day by a GitHub Actions workflow and stored with the statistics ([#45](https://github.com/leonardovida/icey/pull/45)).

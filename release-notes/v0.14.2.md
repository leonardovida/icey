## Highlights

- **Items stay in their section when their app recreates them.** Some apps, such as Docker, put their item back at the far left each time they launch, which landed it in the always-hidden section. Icey now moves it back to the section it was in ([#70](https://github.com/leonardovida/icey/pull/70), [jordanbaird/Ice#6](https://github.com/jordanbaird/Ice/issues/6), [jordanbaird/Ice#732](https://github.com/jordanbaird/Ice/issues/732)).
- **Release notes in the update window.** When Icey offers an update, the window now lists what changed in that version, instead of only linking to GitHub ([#68](https://github.com/leonardovida/icey/pull/68)).

## Features

- **Release notes in the update window:** the notes for each new version, with its highlights, fixes and anything you need to do, appear in the window that offers the update. The notes come with the update itself, so the version you are updating from shows them too ([#68](https://github.com/leonardovida/icey/pull/68)).

## Bug Fixes

- **Items back in the always-hidden section after their app restarts:** an app that doesn't keep its item's position put the item at the far left on every launch, and Icey moved it only the first time it saw the app. Icey now remembers each item's section and moves such an item back, while an item you move yourself stays where you put it. This applies to macOS 14 to 26 ([#70](https://github.com/leonardovida/icey/pull/70), [jordanbaird/Ice#6](https://github.com/jordanbaird/Ice/issues/6), [jordanbaird/Ice#732](https://github.com/jordanbaird/Ice/issues/732)).

More fixed Ice issues are listed on the [fixes page](https://leonardovida.github.io/icey/fixes/).

## Compatibility

- **Remembered sections start now:** Icey learns each item's section from this version on, so an item that is already in the always-hidden section stays there until you move it once. Nothing else to do.

## Highlights

- **Screen Recording is detected correctly.** Icey no longer reports the permission as missing when one menu bar item has no title ([#86](https://github.com/leonardovida/icey/pull/86), [jordanbaird/Ice#896](https://github.com/jordanbaird/Ice/issues/896)).
- **The Ice Bar follows the menu bar's color on every display** ([#87](https://github.com/leonardovida/icey/pull/87)).

## Bug Fixes

- **Screen Recording reported as missing:** Icey read the title of only the first menu bar item to check the permission, so an item without a title made it report the permission as missing, which disabled Menu Bar Layout and the item images in the Ice Bar. Icey now checks every item, and still detects a permission that is revoked while it runs ([#86](https://github.com/leonardovida/icey/pull/86), [jordanbaird/Ice#896](https://github.com/jordanbaird/Ice/issues/896)).
- **Ice Bar color on a second display:** on a display other than the main one, the Ice Bar kept the color it had when it opened, through changes of space, appearance or the windows under the menu bar. It now updates on every display. On macOS 27 the Ice Bar keeps its flat color ([#87](https://github.com/leonardovida/icey/pull/87)).
- **Slower item lookups on macOS 26:** macOS ends Icey's helper process from time to time. Icey noticed only when its next request failed, and then looked up menu bar items one at a time for a minute. It now reconnects to the helper before the next request ([#89](https://github.com/leonardovida/icey/pull/89)).

More fixed Ice issues are listed on the [fixes page](https://leonardovida.github.io/icey/fixes/), which now covers all 840 Ice issues ([#88](https://github.com/leonardovida/icey/pull/88)).

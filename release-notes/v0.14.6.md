## Highlights

- **Ten more languages.** Icey is now available in 20 languages, adding Czech, Dutch, Indonesian, Polish, Russian, Swedish, Thai, Turkish, Ukrainian and Vietnamese ([#91](https://github.com/leonardovida/icey/pull/91)).
- **Search matches accents, character width and other scripts.** A search for `cafe` finds Café, full-width letters find Latin names, and `weixin` finds 微信 ([#91](https://github.com/leonardovida/icey/pull/91)).
- **Clearer settings.** The update, rehide, show on hover and Ice Bar settings now explain what they do ([#93](https://github.com/leonardovida/icey/pull/93)).

## Features

- **New languages:** Icey follows the language chosen in System Settings > General > Language & Region. The new translations have not yet been reviewed by native speakers, and corrections are welcome ([#91](https://github.com/leonardovida/icey/pull/91)).
- **Search in any script:** Search Menu Bar Items ignores accents and character width, and also matches the Latin spelling of names written in another script, such as `kakao` for 카카오톡 ([#91](https://github.com/leonardovida/icey/pull/91)).
- **System item names in the app's language:** the names of macOS's own menu bar items, such as Wi-Fi, Battery and Focus, appear in Icey's language instead of as English identifiers. The Space key in hotkeys and the Launch at login setting are translated as well ([#91](https://github.com/leonardovida/icey/pull/91), [#97](https://github.com/leonardovida/icey/pull/97)).
- **Settings explanations:** ([#93](https://github.com/leonardovida/icey/pull/93))
  - The update settings in About state how often Icey checks for updates and when downloaded updates are installed. Automatic downloads are unavailable while automatic checks are off, because Sparkle downloads only what those checks find. Existing update settings are not changed.
  - Show on hover delay moved from Advanced to General, directly below Show on hover, and appears only while Show on hover is on.
  - The Smart and Timed rehide strategies and the Ice Bar describe their behavior precisely.

## Bug Fixes

- **Appearance for one mode only:** an appearance set only for light or only for dark mode did not appear after the system switched to that mode until Icey was restarted, and Hold to Preview showed nothing. It now appears after the switch ([#94](https://github.com/leonardovida/icey/pull/94)).
- **Item section lost while a move was queued:** when an app recreated its item before Icey moved it back to its section, the item could remain in the always-hidden section permanently. Icey now keeps the item's section until the move completes ([#99](https://github.com/leonardovida/icey/pull/99)).
- **Permissions window reopening:** after Continue was clicked without a permission, granting that permission later brought the permissions window and a Dock icon back. The window now returns only while it is still open ([#105](https://github.com/leonardovida/icey/pull/105)).
- **Clicks on system items on macOS 27:** a click on a system item, such as the clock or Wi-Fi, shortly after the camera indicator appeared could be cut short and lost. Each pause of concealment now ends only on its own schedule ([#95](https://github.com/leonardovida/icey/pull/95)).
- **Memory growth:** a control item that moved between displays left an observer behind each time, and on macOS 26 a cache of item identifiers grew for as long as Icey ran. Both are now bounded ([#96](https://github.com/leonardovida/icey/pull/96), [#101](https://github.com/leonardovida/icey/pull/101)).
- **Possible crashes:** two conversions of stored hotkey values could crash on invalid data. They now ignore such values ([#106](https://github.com/leonardovida/icey/pull/106)).

## Maintenance

- **Lower CPU use:** ([#98](https://github.com/leonardovida/icey/pull/98), [#104](https://github.com/leonardovida/icey/pull/104), [#108](https://github.com/leonardovida/icey/pull/108))
  - The menu bar appearance panels observe clicks in other apps only when the split shape is selected, instead of with any appearance.
  - While Screen Recording is not granted, the once-per-second permission check reads all menu bar items in one call instead of about 60 calls.
  - On macOS 27, cutting each item's image out of the menu bar capture is about 2.5 times faster.
- **Code and tests:** unused code is removed, and the macOS 27 logic has 11 more tests ([#100](https://github.com/leonardovida/icey/pull/100), [#102](https://github.com/leonardovida/icey/pull/102), [#103](https://github.com/leonardovida/icey/pull/103), [#106](https://github.com/leonardovida/icey/pull/106)).
- **Release tooling:** the release scripts and the release feed check handle a missing build folder and transient GitHub errors ([#107](https://github.com/leonardovida/icey/pull/107)).
- **Website:** the [website](https://leonardovida.github.io/icey/) explains Icey, its installation, permissions and the switch from Ice more clearly, and is available in 20 languages ([#92](https://github.com/leonardovida/icey/pull/92)).

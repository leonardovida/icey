## Highlights

- **A smaller download.** The download is about 25 percent smaller and the installed app about 45 percent smaller, with no change in behavior ([#111](https://github.com/leonardovida/icey/pull/111), [#114](https://github.com/leonardovida/icey/pull/114), [#115](https://github.com/leonardovida/icey/pull/115)).
- **Less work on macOS 27.** Icey watches clicks only while items are hidden, skips menu bar captures that the Ice Bar cannot use, and processes item images off the main thread ([#110](https://github.com/leonardovida/icey/pull/110), [#113](https://github.com/leonardovida/icey/pull/113), [#116](https://github.com/leonardovida/icey/pull/116)).

## Bug Fixes

- **Hidden items left visible on macOS 27:** when macOS rejected a change to which items are concealed, or did not respond within three seconds, hidden items stayed visible until another event triggered an update. Icey now retries the change with increasing delays ([#112](https://github.com/leonardovida/icey/pull/112)).

## Maintenance

- **Smaller app:** ([#111](https://github.com/leonardovida/icey/pull/111), [#114](https://github.com/leonardovida/icey/pull/114), [#115](https://github.com/leonardovida/icey/pull/115))
  - Release builds no longer include debugging symbols. The compiled code is unchanged.
  - Translations are stored in a compact binary format, and the icons use lossless compression.
  - The release leaves out two Sparkle helper services that only sandboxed apps use. Icey is not sandboxed and installs updates without them.
- **Lower CPU use on macOS 27:** ([#110](https://github.com/leonardovida/icey/pull/110), [#113](https://github.com/leonardovida/icey/pull/113), [#116](https://github.com/leonardovida/icey/pull/116), [#117](https://github.com/leonardovida/icey/pull/117), [#119](https://github.com/leonardovida/icey/pull/119))
  - The click monitor, which every click passes through, runs only while items are concealed.
  - While the Ice Bar is open, Icey no longer captures the menu bar every three seconds when the capture cannot contain any item the Ice Bar shows.
  - Item images are cut out of the menu bar capture off the main thread and about four times faster.
  - The remembered application menu widths are limited per display.
- **Tooling:** continuous integration uses SwiftLint 0.65.1 ([#118](https://github.com/leonardovida/icey/pull/118)).
